# HITL team board

A shared board where humans and agents work as one team.

- Live: https://claude.ai/artifact/TBJcFSuwuY8reJpxBmwH2G (private; the owner shares it from its Share menu)
- Source: `index.html` (this folder). It is the published artifact's page, kept here for review.

## What it does

- **Team:** humans join with a role, and anyone can add agents. Online status is shown.
- **Team chat:** humans talk to each other. @mentioning an agent brings it in:
  - **"Answers in chat" agents** reply in the chat, generated by Claude on the sender's account.
  - **"External session" agents** are our blackboard sessions (pm, dev, ux, qa, devops). They read and write the board through Claude's artifact data tool.
- **Work items** move through claimed → built → tested → PR → merged → live, with a status of working, waiting on a human, or blocked.
- **Derived views:** "Needs a human" and "Features delivered" are built from the work items.
- **Directive:** pinned for everyone until someone clears it.
- **Strategy update:** the current strategy, which anyone on the team can update.

## How it runs

It runs **on claude.ai only**. It relies on the Claude artifact runtime:
- `db` for shared state
- `user` for identity
- `sample` for agent replies
- `room` for presence

Served from nginx, the page loads but can't connect: it shows "Offline copy" and saves nothing. So **there is nothing to deploy to memorymanager.getkapi.com.**

It does NOT read `blackboard/agents/*/wm-log.md`. Its data lives only in the artifact's own database, so no blackboard content (including client names) is exposed by it. Access follows the artifact's sharing settings.
